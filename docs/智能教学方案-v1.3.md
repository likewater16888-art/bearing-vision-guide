## 1. 现状诊断：为什么"像文档重组"，不像"教学"

v1.2 已经有很好的**素材层**（这是必要的，不是白做）：

| 已有数据 | 数量 | 教学价值 |
| --- | --- | --- |
| 手册全文结构化 | 519 节 / 355 图 / 147 表内图 | 权威依据、可跳转锚点 |
| 工位 | 3（外径 / 内径 / 端面） | 学习单元骨架 |
| 检测项（teach.items） | 32（8 / 7 / 17） | 判据、合格区间、"看到什么调什么" |
| 参数（params） | 30（4 / 12 / 14） | 可出计算/推理题 |
| 缺陷（defects） | 30（8 / 13 / 9） | 可出图片判读题 |
| 亮度锚点（brightness.anchors） | 17 | 可出"这张像合格吗"题 |
| 标准流程（teach.flow） | 23 步 / 44 图 | 可出排序题、跳步纠错题 |
| 陷阱（pitfalls） | 10 | 可出"下一个动作选什么"题 |
| 案例（cases） | 16（漏检 2 / 误判 9 / 定位失败 5） | 可做情景排障主线 |
| 问答（teach.qa） | 24 | 可做卡片背面/追问 |
| 术语（glossary） | 32 | 可出术语配对题 |
| 红线（redlines） | 8 | 可出"绝对不能做"单选题 |
| 上岗自检（checklist） | 11 | 可做结业实操清单 |
| 型号矩阵（teach.models） | 4 类 | 可出选型判断题 |

**问题不在数据，在交互形态。** 现在六个入口（全文 / 速查 / 流程图 / 参数表 / 案例 / 自检）全是"只读"：
用户能**看到**答案，但系统从不**问他**、不**判他**、不**记他**。所以：

- 读完 ≠ 会做。没有主动回忆，遗忘曲线照常生效（现场 3 天不碰就忘）。
- 不会的人不知道该读哪一节，会的人也只当字典用 —— 缺**路径**（从 0 到独立调参的次序）。
- 图片是"配图"，不是"考题"。而这个岗位最难的是**眼力**（欠曝/过曝/该调哪个参数），必须靠判读训练。
- 没有掌握度账本，班组长无法回答"这个人能不能独立上机"。

一句话：v1.2 是**知识库**，缺的是**教练**。

## 2. "智能教学"在本项目里的定义（离线可落地）

不做"接个大模型聊天"那种智能（离线、file://、无外网、不能编数值）。这里的智能 = **五件事形成的闭环**：

1. **图谱化**：把手册切成可考核的原子知识点（KP），带前置依赖、原文锚点、图。
2. **提问**：由 KP 自动/半自动生成 6 类题型，按掌握度调度（不会的多问、会的少问）。
3. **判分 + 定向反馈**：答错不说"错了"，而说"你选了 X，但手册 §7.7 第三步要求先关存图，否则……→ 去读这一段"。
4. **调度**：间隔重复（SM-2 简化）+ 掌握式门槛（KP 未达标不放行下一课）。
5. **记账**：本地掌握度热力图、错题本、能力雷达、可打印学习档案 → 支撑"能否上岗"的判断。

对应学习科学依据：主动回忆（testing effect）、间隔重复、变式训练（同一判据换图换工位）、刻意练习（只练弱项）、即时反馈、掌握式学习（mastery gating）。这些都是**规则可实现**的，不需要神经网络。

## 3. 目标能力模型（学完要能干什么，用这 6 维验收）

| 维度 | 能力描述 | 检验方式 |
| --- | --- | --- |
| A 成像判读 | 看一张像，判断合格/欠曝/过曝/发黑/反光/脏污，说出该动谁 | 图片判读题（60–80 张） |
| B 参数推理 | 给现象+现值，推出该调哪个参数、往哪调、为什么不能反着调 | 单选 + 填空 + 沙盘 |
| C 检测项配置 | 按产品类型（密封圈/防尘盖/金属/尼龙保持架）配阶段数、检测项、面积/个数 | 型号矩阵判断题 |
| D 定位校准 | 识别区域、灰度定位四边、内/外圈半径、二段字符识别 | 步骤排序 + 参数填空 |
| E 排障链路 | 从"漏检/误判/定位失败"走到根因，顺序正确（不跳步） | 情景决策树（30 条） |
| F 红线与边界 | 绝不做的动作（置信 0.9、开存图量产、未采图就调参…） | 红名单选（必须 100%） |

结业线建议：A ≥ 85%、B ≥ 80%、C/D ≥ 80%、E ≥ 80%、F = 100%，总分 ≥ 80 才算"可独立调参"。

## 6. 五个模块详设（这是"教"的主体）

### M1 学习路径（`#/learn`）— 从 0 到能独立调参的次序

14 课、三段递进，前置未达标则下一课锁定（显示"为什么锁"）：

| # | 课 | 主要 KP | 练习 | 现场作业 |
| --- | --- | --- | --- | --- |
| 1 | 这台设备在干什么（检测链路 6 步） | 成像→定位→识别→判定→输出→复判 | 3 题 | 指出自己机台的 6 个环节 |
| 2 | 三类工位与四次定位 | 端面/内径/外径、粗定位/精定位/灰度定位/字符 | 4 题 | 说出本岗位用哪几个定位 |
| 3 | 安全与红线（F 维） | redlines 8 条 + 存图模式 | 10 题（必须 100%） | 复述 3 条红线 |
| 4 | 外径：成像核到位（欠曝/过曝/旋转） | od.brightness 7 锚点 | 6 图片题 | 采 3 张不同曝光图 |
| 5 | 外径：七步流程走一遍 | od.flow 7 步 | 排序题 + 2 情景 | 在机台上按序做一遍 |
| 6 | 外径：参数与缺陷（缺料/伤/尺寸） | od.params + od.defects | 8 题 | 记录当前参数 |
| 7 | 内径：低曝光与倒角发黑 | id.brightness + id.defects | 6 图片题 | 采倒角图 2 张 |
| 8 | 内径：八步流程 + 灰度链路 | id.flow 8 步 + teach.pipeline | 排序 + 3 情景 | 走一遍灰度链路 |
| 9 | 内径：检测项配置（13 项） | id.teach.items 7 + defects 13 | 8 题 | 对照本产品配置 |
| 10 | 端面：五阶段成像（核心中的核心） | face.stage1–5 | **12 图片题** | 逐阶段采图各 1 张 |
| 11 | 端面：四类型检测项开关 | face.teach.items 17 + models 4 | 10 题 | 按产品类型开关 |
| 12 | 端面：八步流程 + 内/外圈定位校准 | face.flow 8 步 + 四条边界 | 排序 + 填空 | 校准一次并记数 |
| 13 | 排障：漏检 / 误判 / 定位失败 | cases 16 + pitfalls 10 | **5 条情景树** | 复现 1 个历史故障 |

每课界面固定四段：**本节课要会什么（1 句 + 3 个判据）→ 关键图（手册原图，2–4 张带"看什么"）→ 3 道即时回忆题（答错立刻讲解 + 原文锚点）→ 现场作业勾选**。学完即算 KP 进 box1。

### M2 卡片复习（`#/learn/review`）— 抗遗忘

- 队列来源：到期卡片（SM-2 简化：again 10 分钟 / hard 1 天 / good 3 天×box / easy 7 天×box，box 封顶 5）。
- 每日目标 10–15 分钟、20–30 张；首页显示"今日复习(12)"。
- 卡片正面优先**图片或判断**（"这张像合格吗"），避免变成名词解释背诵。
- 每张卡背面固定两行：结论 + 为什么；底部 `手册 §x.y →` 直跳全文。

### M3 判读训练（`#/learn/drill/img`）— 练眼力（本岗位最关键）

- 题库 60–80 张，从 355 张原图里选（欠曝/过曝/合格/倒角发黑/频闪相位/暗斑亮斑/保持架反光/四条边界/字符识别正确·错误）。
- 三种问法轮换：① 这像属于哪类问题 ② 该动哪个参数、往哪调 ③ 这属于哪个阶段/哪个检测项。
- 答错强制看"对照图"（合格 vs 不合格并排），这是 v1.2 数据里最有价值但当前只作"配图"的部分。
- 记录 A 维掌握度，独立形成"眼力"分数。

### M4 情景排障（`#/learn/drill/scene`）— 最像"导师"的部分

- 30 条决策树（外径 8 / 内径 10 / 端面 12），来源：cases 16 的真实故障 + pitfalls 10 + flow 的步序 + qa 24。
- 交互：给现象（可带图）→ 学员每次只选"下一步做什么"→ 系统不提前剧透 → 走完再复盘：逐节点标 ✓/✗ + 手册依据 + 你的路径与标准路径的分叉点。
- 关键设计：**跳步有代价**（-1 ~ -2 分并解释后果），让"先关存图、先核成像、最后才动参数"变成肌肉记忆。
- 出口：把该场景涉及的 3 个 KP 自动加入复习队列（错哪补哪）。

### M5 参数沙盘（`#/learn/sandbox`）— 理解"为什么"

- 选工位 + 检测项，出现手册里的真实参数（置信/最小像素面积/最小缺陷个数/暗斑三级/灰度差/曝光/阶段数/张数）。
- 学员拖动或填值，系统按**规则引擎**（把手册判据写成 if 规则，不是 AI）预测：漏检↑/误判↑ 风险、是否触碰红线、该参数是否属于本阶段可动项。
- 例：置信 0.75→0.80 立即红字"≥0.8 等同没开此项；0.9 禁止"并锁死；面积调到 20 px 提示"低于按管控最小缺陷面积 → 漏检"。
- 目的：让"参数-后果"因果可见，配合 B 维题目。

## 7. 考核 / 错题本 / 答疑

### 7.1 结业卷（`#/learn/exam`）

- 30 题：A 图片 8 / B 参数 8 / C·D 配置定位 5 / E 情景 3 / F 红线 4（红线任一错 → 直接不通过）。
- 80 分通过；限时可选（默认不限时，班组长模式可开 30 分钟）。
- 出分页：总分 + 六维雷达 + "你的薄弱 3 个 KP" + 一键生成补学清单（3 节原文 + 对应图 + 5 道同类题）。
- 打印：复用现有打印样式，输出《调参能力评估单》（姓名/日期/分数/雷达/签字栏），交给班组长归档。

### 7.2 错题本（`#/learn/wrong`）

- 按 KP 归并（同一知识点错 3 题 = 1 条），显示错因归类（记错数值 / 混淆工位 / 跳步 / 眼力误判）。
- 出本条件：该 KP 连续 2 次答对且间隔 ≥ 1 天。
- "只练错题"模式：从错题直接生成 10 题小卷，做完即时更新掌握度。

### 7.3 本地答疑（`#/learn/ask`，可选）

- 输入自然语言（"端面凹陷一直漏检怎么办"）→ 同义词表 + 分词打分检索 KP/情景树 → 输出：结论 + 依据条款 + 上手步骤 + 相关图 + 相关案例，并给"仍未解决 → 按 §8.5 采图交算法"的边界。
- 只做检索与组装，**不生成新事实**，杜绝编数值。
- 可选（默认关闭）：允许填 OpenAI 兼容 API（URL+Key 存本地），仅用于"换个说法解释已有结论"，输出必须附原文锚点；不联网也能全功能使用。
